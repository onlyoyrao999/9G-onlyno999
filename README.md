## 📌 项目概述 (Overview)

`9G-onlyno999` 是一款专为**仙法打斗漫剧、短剧、修仙动画、2008 经典港产玄幻/动作大片、院线级真人实拍东方玄幻特效电影以及硬核全场景现代动作死斗**打造的专业 3×3 九宫格分镜生成与动作拆解系统。

本系统深度研习并逐帧解析了以 2008 年代为代表的经典香港玄幻动作大片（如《风云》《蜀山传》《龙虎门》《功夫》）核心视频片段的**色彩基调搭配、年代影调、真气法术特效与武指招式设计**，并深度融合了**顶级打斗丝滑运镜心法（一镜到底长镜头、动感手持跟拍、出招即换向甩镜、贴身中景低机位、镜头不停/环境挨打/重力落体物理实感）**以及四大硬核实战/奇幻参考基准，将一个完整的大招或格斗释放过程拆解为符合院线工业标准的 **9 大连贯分镜镜头**，并支持多流派法术一键替换、角色人设特征图锁定、九宫格高精度自动切片、动漫画板循环播放与多平台提示词（Midjourney / Flux / Imagen / Gemini）一键导出。

## ⚡ 核心交互准则 (Core Operating Principle)

> **🎯 准则声明**：
> **当用户需要画九宫格时，系统才执行 3×3 矩阵图像绘制与分镜切片；未指定画图需求时，默认按结构化分镜提示词工程（Prompt Compilation）格式精准输出。**

1. **按提示词输出模式 (默认)**：
   * 优先输出包含 2008 港片调色、丝滑运镜指令、四大实战参考指令、9 大连贯分镜逐镜调度与中英文母版提示词。
   * 支持一键复制 Midjourney v6.1、Flux / SDXL、Gemini / Imagen 与负向提示词。
   * 极速响应，便于作为提示词工程中心与视频 AI 首尾帧参数基准。
2. **九宫格绘图与分镜渲染模式 (按需触发)**：
   * 仅在用户明确需要或点击【🎨 立即绘制九宫格】时执行绘图。
   * 调用 Imagen 3 视觉模型绘制完整 3×3 全景母图，自动裁切为 9 张独立 16:9 影视切片。
   * 激活 9 帧连贯动态漫剧播放器与 ZIP 一键打包导出。

## 🎥 高手打斗丝滑运镜四大核心心法 (Seamless Fight Cinematography)

```text
┌─────────────────────────┬─────────────────────────┬─────────────────────────┬─────────────────────────┐
│ 1. 一镜到底 零剪辑点   │ 2. 动感手持与招式甩镜   │ 3. 中景贴身与低机位仰拍 │ 4. 镜头不停 环境挨打   │
│ Continuous One-Take     │ Handheld & Whip-Pan     │ Medium Dynamic Tracking │ Environmental Reaction  │
└─────────────────────────┴─────────────────────────┴─────────────────────────┴─────────────────────────┘
```

1. **一镜到底，拒绝剪辑 (Continuous One-Take, Zero Cuts)**：全段 10 秒+ 连贯长镜头，零剪辑点硬切，动作势能自然流转。
2. **动感手持与出招甩镜 (Handheld & Whip-Pan Tracking)**：镜头不落定，出招转向微秒级甩镜，前推跟随冲向对手不后退。
3. **中景贴身与低机位仰拍 (Medium & Low-Angle)**：贴身中景保留神情与全身动作，16-28mm 低角度仰拍拉满压迫感。
4. **环境挨打与真实物理重力 (Environment Reaction & Weight)**：出招激扬沙土与逆光造势，震碎青石地砖撞翻摊位；兵器交错火星四溅，起跳失重与落地沉坠重力感。
